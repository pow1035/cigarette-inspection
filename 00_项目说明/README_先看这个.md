# 烟支检测项目整理说明

## 项目定位

这是烟厂给出的烟支外观在线检测项目资料。项目核心目标是开发一个基于 Qt/C++ 的上位机，用于接入工业相机、IO/控制板和卷烟机同步信号，对烟支外观缺陷进行检测、显示、保存和剔除。

现有资料体现出两条技术路线：

1. 老版本上位机：以 Halcon 传统视觉算法为主，已有相机采图、队列处理、缺陷判断、IO 剔除等闭环代码。
2. 新方向：使用深度学习模型进行缺陷检测，已有 YOLO/TensorRT 推理验证代码和模型文件，但还没有完整接入新版 Qt 上位机闭环。

## 整理后的目录

### 01_上位机_QT_新版_CigVision

当前看起来是后续应继续开发的新版上位机工程。主要特点：

- Qt + Visual Studio 工程。
- 主窗口为 `CigVision`。
- 已有参数管理、品牌参数、系统参数、相机初始化、IO 读取线程。
- 图像算法被拆成 `process.dll` 形式。
- 目前还没有完整接回老版的图像处理、保存、剔除闭环。

### 02_上位机_QT_老版_传统算法

这是传统算法版本，参考价值很高。主要特点：

- 基于 Qt + Halcon。
- 传统算法在 `process.cpp`、`process2_1.cpp` 等文件中。
- 有较完整的生产者-消费者队列逻辑。
- 有 `reject.cpp` 通过 PCIE-1730 写 IO 剔除编号。
- 后续迁移新版时，应重点参考这里的运行闭环。

### 03_深度学习模型与TensorRT

这是深度学习检测路线相关资料。包含：

- YOLO/TensorRT C++ 推理源码。
- PyTorch、ONNX、TensorRT engine 模型文件。
- 导出、部署、排错文档。

当前判断：这部分是独立验证包，还没有真正集成进 Qt 上位机主流程。

### 04_测试数据与样例图片

包含推理测试图片、视频、缺陷样例和图片压缩包。用于后续验证传统算法或深度学习模型效果。

### 05_项目文档与汇报

包含技术报告、汇报 PPT、演示视频。用于理解项目背景、硬件结构、算法流程和现场需求。

### 06_硬件电路资料

包含单片机/控制板相关 Altium 资料压缩包，以及从 PDF 中提取出的原理图和 BOM。它主要是硬件电路资料，不是 MCU 固件源码。

### 07_运行环境与依赖包

单独保存环境安装包和可运行的 AI 推理测试包，不和源码混在一起。包含：

- Qt 5.9.9 Windows 安装包。
- OpenCV 4.8.0 Windows 安装包。
- 从 `expert_test/build_trt/Release` 提取的 AI 推理测试运行包。

这个目录体积较大，但用于复现原作者在 Windows 上的 TensorRT 测试环境有价值。如果以后只做源码开发，可以临时不拷贝这个目录；如果要去现场机部署或验收模型推理速度，这个目录很有用。

### 99_原始资料与未纳入说明

记录哪些文件没有放进整理版，以及原因。

## 当前开发重点判断

你说的方向是对的：项目主线应该是做烟支检测上位机，Qt 开发，老版用传统 Halcon 算法，现在要逐步替换或增加深度学习检测算法。

更准确地说，下一步不是单纯写一个 YOLO demo，而是要把深度学习检测接入上位机工业闭环：

1. 相机回调采图。
2. 图像进入待检测队列。
3. 深度学习模型推理。
4. 输出缺陷类别、位置、置信度。
5. 根据烟支编号和工位延迟生成剔除编号。
6. 保存缺陷图和统计信息。
7. UI 实时显示结果。

## 建议下一步

先不要急着大改界面。建议下一步做“老版闭环迁移清单”：

- 从老版搬回采图队列、处理线程、保存线程、剔除线程的核心结构。
- 把传统算法调用点抽象成检测接口。
- 新增 YOLO/TensorRT 检测实现。
- 保留传统算法作为可切换或兜底方案。
- 最后再整理参数界面和品牌参数。
