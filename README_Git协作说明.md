# 烟支检测项目 Git 协作说明

这个仓库建议用于同步源码、项目说明、小型文档和可控大小的模型文件。

没有直接纳入 Git 的内容：

- `07_运行环境与依赖包/`：Qt、OpenCV、CUDA/TensorRT DLL、测试运行包等，体积过大。
- `04_测试数据与样例图片/图片压缩包/images----OK.zip`：超过 GitHub 普通文件限制。
- `05_项目文档与汇报/张烟-卷烟机烟支外观在线检测系统的研发-建院.pptx`：超过 GitHub 普通文件限制。

协作建议：

1. GitHub 仓库请设置为 private，避免烟厂项目资料外泄。
2. 平时主要提交源码、参数、说明文档和小样例。
3. 大安装包、完整测试数据、运行时 DLL 建议用网盘、企业微信文件、NAS 或 Git LFS 单独管理。
4. 如果后续要把模型、数据集也纳入版本管理，再统一改成 Git LFS 方案。
