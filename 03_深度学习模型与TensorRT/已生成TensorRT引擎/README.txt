================================
立即开始测试(3步)
================================

1. 打开命令提示符(cmd)
   快捷键: Win + R, 输入 cmd, 回车

2. 进入Release目录
   cd E:\code\yolo26\expert_test\build_trt\Release

3. 运行测试
   test_yolo_trt_v2.exe image yanzhi20260115.onnx test.jpg

   首次运行需要5-10分钟构建TensorRT引擎,请耐心等待
   构建完成后会自动保存缓存,下次运行秒开

================================
查看关键指标
================================

在输出中找这一行:
   Inference time: X.X ms

✅ 目标: X.X < 5.0 ms

================================
运行性能基准测试
================================

首次测试成功后,运行:
   test_yolo_trt_v2.exe benchmark yanzhi20260115_cache.engine test.jpg

输出会显示详细的性能统计:
   - 平均推理时间 (Mean)
   - 最小/最大时间
   - P95/P99延迟
   - 吞吐量(FPS)

================================
测试其他图片
================================

复制任意图片到Release目录,然后:
   test_yolo_trt_v2.exe image yanzhi20260115_cache.engine your_image.jpg

结果保存在: output_your_image.jpg

================================
测试视频
================================

   test_yolo_trt_v2.exe video yanzhi20260115_cache.engine your_video.mp4

按 'q' 退出
