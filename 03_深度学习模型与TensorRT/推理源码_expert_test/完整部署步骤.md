## 步骤2: 编译C++代码 (2-5分钟)

### 2.1 打开 x64 Native Tools Command Prompt for VS 2022

（在开始菜单搜索"x64 Native Tools"）

### 2.2 运行编译命令

```cmd
cd e:\code\yolo26\expert_test
mkdir build
cd build

cmake .. -G "Visual Studio 17 2022" -A x64 -DCMAKE_BUILD_TYPE=Release

cmake --build . --config Release
```

**预期输出:**
- `build\bin\Release\test_yolo_tensorrt.exe`

**常见问题:**

1. **找不到OpenCV**
   - 安装: `vcpkg install opencv:x64-windows`
   - 或下载预编译版: https://opencv.org/releases/
   - 在cmake时指定: `-DOpenCV_DIR=C:\opencv\build`

2. **找不到CUDA**
   - 确保安装了CUDA Toolkit 11.8
   - 检查环境变量: `CUDA_PATH`

## 重要提醒

### 关于输入尺寸 (992x992)

你的模型使用992x992分辨率，但C++代码默认是640x640。

需要修改 `test_yolo_tensorrt.cpp` 第160行左右：

```cpp
// 原来
YOLOTensorRT detector(engine_path, 640, 0.25f, 0.45f);

// 改为
YOLOTensorRT detector(engine_path, 992, 0.25f, 0.45f);
```

或者重新编译时会自动匹配引擎的输入尺寸。
