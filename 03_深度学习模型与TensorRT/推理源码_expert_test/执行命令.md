## 方法2: 手动执行（推荐理解每一步）

### 在 Anaconda Prompt 中执行：

```powershell
# 1. 激活环境
conda activate yolo26

# 2. 安装ultralytics（只需一次）
pip install ultralytics

# 3. 进入目录
cd e:\code\yolo26\expert_test

# 4. 运行导出脚本
python export_tensorrt.py
```

## 如果遇到错误

### 错误1: ultralytics未安装
```cmd
pip install ultralytics
```

### 错误2: TensorRT导出失败
检查：
- TensorRT是否已安装
- 显存是否充足
- 减小workspace: 编辑export_tensorrt.py，改为workspace=8或4

### 错误3: 路径问题
确保从expert_test目录运行，或使用绝对路径：
```cmd
python e:\code\yolo26\expert_test\export_tensorrt.py
```
