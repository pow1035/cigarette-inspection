## 🔍 编译过程中解决的问题

### 问题1: CMake找不到CUDA编译器
**错误:** `CUDA Toolkit v11.8 directory '' does not exist`
**原因:** CMakeLists配置了CUDA语言但nvcc未正确安装
**解决:** 移除CUDA语言要求,只保留C++,仅链接CUDA运行时库
```cmake
# 修改前: project(YOLO26_TensorRT_v2 CUDA CXX)
# 修改后: project(YOLO26_TensorRT_v2 CXX)
```

### 问题2: OpenCV CMake配置文件未找到
**错误:** `Could not find a package configuration file provided by "OpenCV"`
**原因1:** Conda OpenCV不包含CMake配置文件
**原因2:** 用户提供的OpenCV路径指向build目录,但实际CMake配置在x64/vc16/lib下
**解决:** 修改OpenCV_DIR指向正确路径
```cmake
set(OpenCV_DIR "E:/code/opencv/build/x64/vc16/lib")
```

### 问题3: 缺少cuda_runtime_api.h头文件
**错误:** `Cannot open include file: "cuda_runtime_api.h"`
**原因:** TensorRT头文件依赖CUDA头文件,但未配置CUDA include目录
**解决:** 添加CUDA include目录到CMakeLists
```cmake
include_directories(${CUDA_TOOLKIT_ROOT_DIR}/include)
```

### 问题4: 链接器找不到cudart.lib
**错误:** `fatal error LNK1181: cannot open input file "cudart.lib"`
**原因:** 未配置CUDA库目录
**解决:** 添加CUDA库目录到link_directories
```cmake
link_directories(${CUDA_TOOLKIT_ROOT_DIR}/lib/x64)
```

### 问题5: std::accumulate未定义
**错误:** `"accumulate": is not a member of "std"`
**原因:** 缺少<numeric>头文件
**解决:** 在test_yolo_trt_v2.cpp中添加`#include <numeric>`

## 💡 技术要点

### 为什么选择运行时构建引擎?

**传统方法的问题:**
- trtexec工具有DLL依赖问题
- 需要手动运行命令行工具
- 用户体验不好

**我们的方案优势:**
1. **零额外步骤** - 用户只需提供ONNX文件
2. **自动优化** - 针对实际GPU自动优化
3. **一次构建,永久使用** - 引擎缓存机制
4. **性能等价** - 与trtexec构建的引擎性能完全相同
5. **易于集成** - 单个ONNX文件即可集成到其他项目

### 核心代码架构

```cpp
YOLOTensorRTv2::YOLOTensorRTv2(model_path) {
    if (is_onnx_file(model_path)) {
        if (cache_exists) {
            loadEngine(cache_path);  // 秒开
        } else {
            buildEngineFromOnnx(model_path);  // 首次:5-10分钟
            saveEngine(cache_path);
        }
    } else {
        loadEngine(model_path);  // 直接加载.engine
    }
}

vector<Detection> YOLOTensorRTv2::detect(image) {
    preprocess(image);           // CPU: resize, normalize
    inference();                 // GPU: TensorRT推理
    postprocess();               // CPU: 坐标转换, NMS
    return detections;
}
```

   ```
   deployment/
   ├── your_app.exe

   └── class_names.txt (可选)
   ```

3. **代码示例**
   ```cpp

   // 初始化(首次会构建引擎)
   YOLOTensorRTv2 detector("model.onnx", 992);

   // 加载图像
   cv::Mat image = cv::imread("test.jpg");

   // 推理
   auto detections = detector.detect(image);

   // 处理结果
   for (const auto& det : detections) {
       std::cout << "Class: " << det.class_id
                 << " Conf: " << det.confidence
   ```
