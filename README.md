# 烟支外观检测上位机

工业级烟支外观质量检测系统：Qt/C++ 上位机 + TensorRT GPU 批量推理 + 完整的本地验证证据链。

从传统视觉检测逐步升级为**可验证的深度学习检测闭环**——不是"能跑就行"的 demo，每一阶段都有独立的验收门和证据留存。

## 核心能力

| 模块 | 说明 |
| --- | --- |
| **新版上位机 CigVision** | Qt/C++ 工程：实时流、多相机、模拟剔除、复核工作台、品牌参数配置 |
| **深度学习推理** | TensorRT 10 GPU 批量推理，结构化结果 + 带框图输出 |
| **传统算法参考** | 老版工程保留，作为迁移前的基线对照 |
| **仿真与稳定性** | SDK-free 多相机仿真、乱序/重复/跳号、队列溢出、P95 时延、停止重启模型 |
| **验证门** | 81 项 Python 测试清单 + C++ 契约测试 + ASan/UBSan + 连续运行防假绿测试 |

## 快速验证

```bash
# 核心门（CI 使用的精确计数门，拒绝测试少发现或零发现假绿）
./scripts/run_all_local_gates.sh --core

# 全量门（另跑 C++14、20 次优化仿真和 ASan/UBSan）
./scripts/run_all_local_gates.sh --full
```

## 工程纪律

- **防假绿**：精确计数门拒绝测试少发现；连续运行测试要求真实 CPU 时间下限，pure-sleep 伪 runtime 会被拒绝
- **证据链**：正式运行把编译器契约、源码快照、可执行文件一并冻结进 evidence，独立 verify 可离线复验
- **诚实边界**：无人工 ground truth 时只证明推理链可运行，不声明商业准确率；现场硬件（相机/卷烟机同步/DAQNavi）验证冻结待恢复

详细阶段验收（P0–P8）见 [README_DEV.md](README_DEV.md)。
