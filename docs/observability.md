# 可观测性设计

## 当前状态

P0 只定义运行证据要求，未修改运行代码，因此不声明日志、指标或性能检查已实现。

## 统一事件字段

后续结构化日志至少包含：时间、级别、组件、事件名、run_id、frame_id、工位、相机、烟支编号、线程、耗时、结果和错误码。模型事件还需记录模型哈希/版本、输入尺寸和阈值版本；剔除事件还需记录模拟/真实模式和目标输出。

## 必需事件

| 组件 | 事件 |
| --- | --- |
| 启停 | 配置加载、依赖检查、启动完成、停止请求、线程退出、异常终止 |
| 相机 | 发现、映射、打开、开始采集、回调错误、队列满、断连、重连 |
| IO 输入 | 设备打开、位变化、烟支编号更新、读失败 |
| 检测 | 模型加载、预处理、推理、后处理、空结果、异常、逐帧时延 |
| 结果 | OK/NG、缺陷类型、规则版本、统计更新 |
| 保存 | 任务入队、保存成功、失败、磁盘空间告警、丢弃 |
| 剔除 | 命令生成、模拟执行、真实执行、安全门拒绝、写失败 |

## 指标

- 帧接收数、处理数、丢弃数和积压深度。
- 预处理、推理、后处理、端到端时延的 P50/P95/P99。
- OK/NG 数、按缺陷类别计数、模拟/真实剔除数和失败数。
- 保存成功/失败数、磁盘剩余空间。
- 进程内存、GPU 显存、CPU/GPU 利用率和连续运行时长。

指标阈值在 OD-04、OD-06、OD-07 确认后写入验收标准。

## 阶段证据

- P3：离线回放日志、逐帧追踪和队列行为。
- P4：模型加载、输出解析、准确率汇总和推理时延。
- P5：相机/IO 输入、模拟剔除编号和停止行为。
- P6：真实硬件操作日志与人工 QA 报告。
- P7：长时运行资源曲线、故障注入和恢复证据。

若完整日志框架在早期过重，先使用带固定字段的 UTF-8 滚动文件日志；限制必须写入 `known-issues.md`，不能用零散 `qDebug()` 作为最终证据。

## P1 构建证据

P1 需保存 Windows 环境检查输出、MSBuild 完整日志、退出码、生成文件清单、实际依赖版本和启动错误。当前只收集了 macOS 静态门与 XML 结果，不声明运行时日志、性能或硬件状态已验证。
