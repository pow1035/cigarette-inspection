## P7-01A 新增流程

1. 启动本地离线检测时冻结 run ID、运行模式、检测器版本、参数版本、队列容量和 `realIoEnabled=false`。
2. worker 回调携带 frame/station/camera/cigarette/timestamp/defect/error 元数据。
3. `ProductRuntimeState` 校验并累计 OK/NG/error、逐相机、逐类别、耗时和队列深度；最近结果和诊断事件均有容量上限。
4. “缺陷查询”页显示最近 NG/错误，可由具名复核人标记“确认结果”“需修正”或“误报”，保留备注和时间。
5. 停止、故障和重新启动走显式状态转换；本地模式拒绝 `realIoEnabled=true`。
6. 统计页和诊断页消费同一快照；启动、结束和人工复核时原子写 `product-session.json`，逐帧 UI 回调不做磁盘写。
7. 离线运行中禁止进入参数、品牌和系统设置页，也禁止同时启动在线运行；退出会先停止离线 worker，避免带活动线程直接关闭。

Qt/Windows 的视觉布局、键鼠操作、表格选择和持久化仍需目标机运行证据。本清单支持源码/依赖决策，不替代 Computer Use 或人工 UI QA。
