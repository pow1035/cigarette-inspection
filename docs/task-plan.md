## 审查与 QA 节奏

- 文档阶段：独立 reviewer + 同代理验证 + 文档一致性检查。
- 代码阶段：实现代理自查后，至少一个独立 reviewer；涉及运行行为时增加 QA 和可观测性检查。
- UI 阶段：Windows 本地应用需要 Computer/人工运行证据；Mac 上的代码检查不能替代。
- 硬件阶段：人工 QA 必须由用户或现场人员报告，Codex 只准备步骤和记录证据。
- P3、P5、P7 后评估一次定向清理，P8 前强制清理审查。
